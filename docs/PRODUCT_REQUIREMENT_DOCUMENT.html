1. Executive Summary & Product Vision

Omni-Manage is a purpose-built, high-performance Enterprise Resource Planning (ERP) platform designed specifically to meet the complex operational, financial, and inventory demands of mobile retail stores, authorized device repair centers, and mobile device wholesalers.

Core Value Proposition
Unlike generic retail ERPs, Mobile Shop ERP manages individual device serial numbers (IMEI tracking) through every stage of the product lifecycle: inventory intake, retail sale, wholesale distribution, warranty claim, and diagnostic repair. It combines point-of-sale efficiency with double-entry accounting and HR payroll automation.

1.1 Strategic Objectives

  • End-to-End Serial/IMEI Tracking: Eliminate device fraud, inventory shrinkage, and warranty disputes with 15-digit IMEI lifecycle tracking.
  • Multi-Branch Governance: Seamlessly handle multi-store branch inventory transfers, centralized pricing control, and aggregated financial reports.
  • Integrated Financial Accounting: Automated posting from POS sales, purchase orders, repair bills, and expense vouchers to double-entry general ledgers.
  • Service & Repair Workflow: Digital job sheets, diagnostic updates, technician assignments, and cost estimation for customer repairs.
  • Modern Dynamic Design: Instant switching across 7 custom design themes (including Neumorphism, Glassmorphism, and Neo Brutalism) to match brand preferences.

3. System Architecture & Tech Stack

3.1 Technological Stack Breakdown

Layer Technology Architectural Rationale
Client Framework React 18 + Vite 5 (ESM) Sub-second HMR development, optimal production bundle splitting, SPA speed.
State Management Zustand + TanStack Query v5 Zustand for client theme & auth persistence; TanStack Query for server state caching.
UI Components shadcn/ui + Tailwind v3 + AG Grid Radix accessibility primitives, ERP-grade AG Grid data tables, dynamic theme engines.
Backend Server Node.js 20 (ESM) + Express 4 Modular monolith pattern (`server/modules/`), native async/await.
Database Layer MongoDB 7 + Mongoose 8 Document schema flex for IMEI attributes, fast indexing, atomic transaction sessions.

Validation & Auth Zod + JWT (Bearer + HTTP-Only Cookie) Strict runtime API validation, zero-trust token auth, TOTP MFA support.

4. Comprehensive Module Breakdown (28 System Modules)

4.1 Sales & Point of Sale (POS) [server/modules/sale]

  • Fast Checkout POS: Single-screen POS interface with instant barcode scanner integration and instant 15-digit IMEI lookup.
  • Multi-Payment Splits: Supports Cash, Credit Card, Mobile Financial Services (MFS: bKash/Nagad), and Customer Credit/Due.
  • Invoice Generation: Automatic generation of printable PDF invoices with custom store branding and thermal receipt printer support (80mm / 58mm).
  • Sales Return & Refund: Restocking fee calculation, IMEI status restoration (`Sold` -> `In Stock`), and automated customer credit note issuance.

4.2 Wholesale Management [server/modules/wholesale]

  • Volume Pricing Tiers: Custom volume discount matrices based on order quantity thresholds per product.
  • Credit Limit Validation: Automated pre-sale checks against customer credit ceiling before wholesale order approval.
  • Bulk Serial Reservation: One-click bulk selection and validation of IMEI lists for large wholesale dispatches.

4.3 Product Catalog & Inventory Master [server/modules/catalog & product]

  • Taxonomy Management: Category, Brand, Model, and Variant hierarchies with custom attribute fields (RAM, Storage, Color).
  • Pricing & Profit Margins: Purchase cost tracking, minimum retail selling price enforcement, and margin threshold warnings.
  • Barcode Management: Internal barcode generation and sticker printing for accessories and non-IMEI inventory.

4.4 IMEI Serial Tracker & Lifecycle Passport [server/modules/imei]

  • Unique Serial Control: Mandatory 15-digit IMEI registration for all mobile phone inventory intake.
  • Lifecycle Status Flow: Strict state machine transitions: In Stock → Sold → In Repair → Returned → Scrapped.
  • IMEI History Passport: Complete timeline audit showing vendor purchase invoice, stock movements, POS invoice, buyer profile, and service repair tickets.
  • Bulk Excel Intake: High-speed CSV/Excel serial importer with instant checksum duplicate detection.

4.5 Multi-Branch Stock & Transfers [server/modules/stock & branch]

  • Branch Stock Isolation: Real-time inventory visibility per store location.
  • Transfer Order Workflow: Inter-branch stock transfer request, dispatch confirmation, in-transit status, and receiving verification.
  • Low-Stock Alerts: Automated notification triggers when product quantity falls below defined safety stock thresholds.

4.6 Device Repair & Job Sheet Management [server/modules/repair]

  • Digital Job Sheets: Ticket generation capturing device condition, passcode/pattern, physical flaws, and customer problem statement.
  • Status Progression: Received → Diagnosing → In Progress → Repaired → Delivered → Cancelled.
  • Billing Integration: Spare parts consumption from inventory and technician labor fees auto-posted to repair revenue ledgers.

4.7 Double-Entry Accounting & Financial Management [server/modules/accounting]

  • Chart of Accounts: Hierarchical structure (Assets, Liabilities, Equity, Revenue, Expenses).
  • Automated Postings: Sales invoices, wholesale orders, vendor purchases, repair bills, and payroll runs automatically generate journal entries.
  • Financial Reports: Real-time General Ledger, Trial Balance, Profit & Loss Statement (P&L), and Balance Sheet generation.

4.8 HR, Attendance & Payroll [server/modules/employee, attendance, leave, payroll]

  • Attendance Tracking: Daily check-in/check-out recording with overtime and late arrival computation.
  • Leave Approval Hierarchy: Employee submission → Manager review → HR final approval with leave balance deduction.
  • Monthly Payroll Processing: Itemized salary slip generation accounting for basic pay, bonuses, leave deductions, and advance adjustments.

Dynamic glowing background mesh gradients with modern dark-mode glowing accents.

7. Integrations & Real-Time Engine

  • Server-Sent Events (SSE): Broadcasts instant notifications from `server/modules/sse` for low-stock alerts, invoice payouts, and repair completion.
  • Browser Event Emitter: Decoupled client-side architecture using native browser event handling (`client/src/utils/EventEmitter.js`).
  • Client-Side PDF Generator: High-performance receipt and invoice generation via `jsPDF` and `jspdf-autotable`.
  • Offline Sync Architecture: Service Worker + IndexedDB wrapper (`offlineDB.js` & `offlineSync.js`) queues offline transactions and syncs automatically when network reconnects.

8. Non-Functional Requirements (NFRs)

Performance API response time < 100ms for 95% of queries. POS barcode lookup < 50ms. Load testing with k6 / Autocannon.

9. DevOps & Deployment Architecture

The system is packaged for containerized deployment via Docker and Docker Compose:

# Production Deployment Architecture
services:
  mongodb:
    image: mongo:7
    ports: ["27017:27017"]
    volumes: [mongo_data:/data/db]

  server:
    build: ./server
    command: node server/server.js
    ports: ["5000:5000"]
    environment:
      - PORT=5000
      - MONGODB_URI=mongodb://mongodb:27017/mobile_shop_erp
      - JWT_SECRET=${JWT_SECRET}

  client:
    build: ./client
    ports: ["3000:80"]
