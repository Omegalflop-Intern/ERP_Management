Performance Optimization Strategies
Frontend Performance:
  1. Code Splitting       → React.lazy() + Suspense (route-based)
  2. Tree Shaking         → Vite auto tree-shakes unused code
  3. Image Optimization   → WebP format, lazy loading, responsive images
  4. Font Loading         → font-display: swap, subset fonts
  5. CSS Purging          → Tailwind purge unused CSS
  6. Memoization          → React.memo(), useMemo(), useCallback()
  7. Virtual Scrolling    → AG Grid handles large datasets
  8. Skeleton Loading     → Instant UI feedback while data loads
  9. Prefetching          → TanStack Query staleTime + prefetch on hover

Backend Performance:
  1. Indexing             → MongoDB indexes on frequently queried fields
  2. Projection           → select() only needed fields
  3. Pagination           → cursor-based or page-based
  4. Caching              → TanStack Query client-side cache
  5. Compression          → gzip/brotli via Nginx
  6. Connection Pooling   → Mongoose connection pool
  7. Rate Limiting        → Prevent abuse
  8. CDN                  → Static assets via CDN

Build Optimization:
  1. Vite Build           → Fast HMR, optimized builds
  2. Minification         → Terser for JS, CSSNano for CSS
  3. Gzip                 → Enable compression
  4. HTTP/2               → Multiplexed connections
  5. Cache Headers        → Static assets: 1 year cache

       │

       │
       ├── 1. cors.config.js          → CORS check (origin allowed?)
       ├── 2. rateLimiter              → Rate limit check (too many requests?)
       ├── 3. auth.routes.js          → Route matching (/auth/login)
       ├── 4. auth.validator.js        → Validation (email valid? password min 6?)
       │
       ▼
auth.controller.js
       │
       │  Calls auth.service.js
       ▼
auth.service.js
       │
       ├── 1. Detect input type (email/phone/username)
       ├── 2. Query MongoDB: User.findOne({ email: ... })
       ├── 3. Compare password: bcrypt.compare()
       ├── 4. Generate JWT tokens
       ├── 5. Save refresh token to DB
       │
       ▼

       │
       │  Return user document
       ▼
auth.controller.js
       │
       │  Send response
       ▼
Client (React)
       │
       ├── Store accessToken in memory
       ├── Store refreshToken in httpOnly cookie
       ├── Redirect to /dashboard
       └── Axios interceptor attaches token to all future requests
